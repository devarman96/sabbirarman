# Sabbir Arman Portfolio (v1.0)

A professional full-stack developer portfolio featuring:
- **React + Vite** for high performance
- **Tailwind CSS** for modern styling
- **Motion** for smooth animations
- **Firebase** integration for backend services
- **Lucide React** for beautiful icons

## Version
sabbirarman.v1.0

## Getting Started
1. `npm install`
2. `npm run dev`
